Grading criteria

Cette grille d'évaluation définit les critères suivant lesquels l'évaluation du projet sera effectuée. Chaque critère est décliné de manière descendante.

Rubric
Faire un usage rigoureux du discours scientifique (mathématiques, physique, informatique) et des outils unidimensionnels associés dans un contexte d'ingénierie ; optimisation, expérience aléatoire, approximation, calcul efficace etc.
A. Les données retenues et variables du problème sont clairement définies. Les contraintes retenues sont spécifiées et transcrites via les données et variables du problème. Le modèle est décrit en détail, en explicitant le lien entre le problème et la méthode de résolution retenue. Les optimisations choisies sont justifiées au vu du contexte.
1 points
B. Les données retenues et variables du problème sont clairement définies. Les contraintes retenues sont spécifiées et transcrites via les données et variables du problème. Le modèle est décrit en détail, en explicitant le lien entre le problème et la méthode de résolution retenue.
1 points
C. Les données retenues et variables du problème sont clairement définies. Les contraintes retenues sont spécifiées, sans les expliciter via les données et variables du problème. Le modèle est décrit en permettant d'expliciter la méthode de résolution retenue.
0 points
D. Les données, variables et contraintes du problème sont listées sans séparation claire entre celles-ci ou en plaçant des éléments dans une mauvaise catégorie. Soit pas de modèle, soit quelques lignes ne donnant qu'une idée vague de la méthode de résolution retenue.
0 points
Non évaluable.
0 points
Identifier les ressources et outils pertinents, à disposition ou à mobiliser pour une éventuelle résolution.
A. Une recherche de méthodes de résolution adaptées est effectuée et une méthode est sélectionnée après comparaison argumentée au vu du contexte.
1 points
B. Une recherche de méthodes de résolution adaptées au problème mène au choix argumenté d'une méthode, sans prise en compte du contexte.
1 points
C. Une méthode de résolution cohérente avec les contraintes du problème est retenue sans comparaison.
0 points
D. Une méthode de résolution est présentée sans vérification de la cohérence avec les contraintes retenues du problème.
0 points
Non évaluable
0 points
Réaliser un prototype à partir d'une solution existante, dans l'objectif de tester sa validité, dans un contexte spécifié et contraint.
A. Sortie de programme opérable (utilisable en conditions réelles, dans un format standard) et lisible. Plusieurs jeux de tests sont proposés. Les goulots d'étranglement sont identifiés, certains ont été traités.
1 points
B. Sortie de programme opérable : utilisable en conditions réelles, dans un format standard. Programme facilitant son utilisation (messages d'aide, interface d'utilisation, etc.). Plusieurs cas sont testés.
1 points
C. Sortie de programme exploitable au moins sur certains cas faciles. Programme paramétrable mais peu pratique à l'utilisation.
0 points
D. Sortie de programme non exploitable, ou non comprise. Pas de découpage en étapes de résolution possible. Aucun paramétrage possible hors du code.
0 points
Non évaluable
0 points
Qualifier l'impact de son entourage sur la société et l'environnement, et vice-versa.
A. Les scénarios proposés sont qualitativement différents. Les choix présentés sont argumentés, étayés avec des sources variées. Les bénéfices et impacts sont identifiés. Des indicateurs sont formulés pour comparer chaque scénario. Une description de l'effet de chaque scénario dans le réel est proposée, avec un retour sur l'hypothèse du scénario. Des effets positifs et négatifs sont pris en compte. Il y a une critique argumentée de chaque scénario.
1 points
B. Les scénarios proposés sont qualitativement différents. Les choix présentés sont argumentés, étayés avec des sources variées. Les bénéfices et impacts sont identifiés. Des indicateurs sont formulés pour comparer chaque scénario. Une description de l'effet de chaque scénario dans le réel est proposée, avec un retour sur l'hypothèse du scénario.
1 points
C. Les scénarios, bien que différents, sont proposés à partir de sources concordantes, du même type. Les bénéfices envisagés se réduisent à un impact direct. Les indicateurs formulés sont quantitatifs et immédiats. Il n'y a pas de retour sur un effet du scénario dans le réel.
0 points
D. Des scénarios différents sont proposés. Il n'y a pas d'arguments pour les choix faits. Des indicateurs sont formulés, mais ne permettent pas d'observer l'impact voulu des scénarios.
0 points
Non évaluable
0 points
